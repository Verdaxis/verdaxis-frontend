# Verdaxis i18n Design — English + Chinese

**Date:** 2026-03-18
**Status:** Approved
**Scope:** Full Vite React app (public pages + authenticated app)

## Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Library | react-i18next + i18next + i18next-browser-languagedetector | Industry standard, namespace splitting, lazy-loading, pluralization |
| Translation files | JSON in repo (`/src/locales/{lang}/{ns}.json`) | Simple, version-controlled, easy to migrate to external service later |
| Public page routing | URL prefix (`/:lang/...`) | SEO-friendly, shareable URLs with language |
| App routing | No prefix, localStorage + user profile | Cleaner URLs, language persisted per user |
| Language detection | Browser detect → localStorage → fallback `en` | Automatic for new users, sticky for returning users |
| Languages | `en` (default/fallback), `zh` | English + Simplified Chinese |

## Architecture

### Two routing strategies, one i18n instance

**Public pages** use `/:lang` prefix:
- `LanguageRedirect` at `/` detects browser language → redirects to `/en/` or `/zh/`
- `PublicLanguageWrapper` reads `:lang` param, validates, calls `i18n.changeLanguage()`
- Legacy redirects for old URLs (`/how-it-works` → `/en/how-it-works`)

**Authenticated app** uses no prefix:
- Language selector in Header/Sidebar
- Persisted to `localStorage` key `verdaxis-lang`
- Synced to user profile `preferred_language` field (optional)
- On login, user profile language overrides localStorage if set

### Language detection priority
1. URL prefix (public pages only)
2. `localStorage` value
3. `navigator.language` / `Accept-Language`
4. Fallback: `en`

## Namespace Structure

```
src/locales/
  en/                          zh/
    common.json                  common.json
    public.json                  public.json
    auth.json                    auth.json
    trading.json                 trading.json
    compliance.json              compliance.json
    dashboard.json               dashboard.json
    fleet.json                   fleet.json
    ai.json                      ai.json
    education.json               education.json
    admin.json                   admin.json
    settings.json                settings.json
    tutorial.json                tutorial.json
```

- `common` loaded eagerly (nav, buttons, confirmations, errors, form labels)
- All others lazy-loaded per route

### Key convention
Flat dot-notation, component-prefixed within namespace:
```json
{
  "sidebar.marketplace": "Marketplace",
  "btn.save": "Save",
  "confirm.trade.title": "Confirm Trade"
}
```

## Component integration

```tsx
const { t } = useTranslation('settings');
<h1>{t('page.title')}</h1>
<button>{t('btn.save', { ns: 'common' })}</button>
```

Data arrays (cards, nav items) use indexed keys:
```json
{ "whyCards.0.title": "Price Discovery", "whyCards.0.body": "..." }
```

## Routing changes (App.tsx)

```tsx
<Routes>
  <Route path="/" element={<LanguageRedirect />} />
  <Route path="/:lang" element={<PublicLanguageWrapper />}>
    <Route element={<PublicLayout />}>
      <Route index element={<LandingPage />} />
      <Route path="how-it-works" element={<HowItWorksPage />} />
      {/* ... all public routes */}
    </Route>
  </Route>
  {/* Legacy redirects */}
  <Route path="/how-it-works" element={<LegacyRedirect to="how-it-works" />} />
  {/* Auth + app routes — no lang prefix */}
  <Route path="/login" element={<LoginPage />} />
  <Route path="/app" element={<ProtectedRoute><Dashboard /></ProtectedRoute>} />
</Routes>
```

## Implementation phases

| Phase | Scope | Components |
|-------|-------|-----------|
| 1. Foundation | i18n infra | Install deps, configure i18next, `common.json`, language selector, `/:lang` routing, legacy redirects |
| 2. Public pages | 17 pages | Extract text → `public.json`, `education.json` |
| 3. Auth flow | 9 pages | Extract text → `auth.json` |
| 4. Core trading | ~15 components | Extract text → `trading.json` |
| 5. Dashboards & fleet | ~15 components | Extract text → `dashboard.json`, `fleet.json`, `compliance.json` |
| 6. Remaining | ~15 components | Extract text → `settings.json`, `admin.json`, `ai.json`, `tutorial.json` |

## Testing
- Existing 209 tests must still pass
- CI check: all keys in `en/*.json` must exist in `zh/*.json`

## What stays English
- Backend API responses (frontend maps to translated strings)
- Console logs, developer-facing text
- Third-party component internals
